# 面向对象编程（OOP）

Java 作为一个面向对象的编程语言，所以要首先理解什么是 OOP。

## 什么是面向对象编程（OOP）

OOP 是一种编程范式（编写代码的指导思想、思考方式等），它将现实世界中的事物抽象为对象，并使用类来定义这些对象的行为和属性。

OOP 先考虑各个对象有什么性质（数据类型），能做什么事情（方法）。

### 面向对象
举一个例子：ATM 机
ATM 机的性质：所属银行-所在支行-编号-位置等。
ATM 机的功能：取款、存款、转账、查询余额等。

所以我们可以创建一个分类： `ATM`，它有性质（数据类型）和功能（方法）。
但是没有赋值或调用等，所以可以把它看作一个蓝图或模板，我们根据这个蓝图往里面放数据并调用方法。

那么什么是对象呢？对象就是根据这个蓝图创建出来的实例，也就是一个具体的 ATM 机。
比如：中国银行-支行-123456-北京。

```Python
class ATM:
    def __init__(self, bank, branch, number, location): 

        #意思是：我们创建一个ATM对象，需要传入bank, branch, number, location等信息

        self.bank = bank
        self.branch = branch
        self.number = number
        self.location = location
        #这个 self.xxx 意思是：我们把传入的信息保存到这个对象本身。
        #比如 ATM1 这个对象 = ATM('中国银行', '支行', '123456', '北京'),我们传入中国银行..等，然后会存到ATM1这个对象本身。
        #则 ATM1 的bank属性就是'中国银行'，branch属性就是'支行'，以此类推,然后我们可以去用了。

        #为什么要self？因为ATM1,ATM2的属性不一样，所以需要用self来存每个对象自己的信息。

    def withdraw(self, amount):
        #取钱
        pass

    def deposit(self, amount):
        #存钱
        pass
```

如何使用：

```Python
ATM1 = ATM('中国银行', '支行', '123456', '北京')
ATM1.withdraw(100) #调用ATM1的取钱方法，取100元
ATM1.deposit(200) #调用ATM1的存钱方法，存200元
```

Java示例
```Java

public class ATM {

    // 属性（数据）
    String bank;
    String branch;
    String number;
    String location;

    // 构造函数
    public ATM(String bank, String number,
               String location, double balance) {

        // this. 表示当前对象自己的属性，与 python self 类似
        this.bank = bank;
        this.number = number;
        this.location = location;
        this.balance = balance;
    }

    // 取款功能
    public void withdraw(double amount) {

        if (amount > balance) {
            System.out.println("余额不足");
            return;
        }

        balance -= amount; //-= 表示 balance = balance - amount

        System.out.println("取款成功");
        System.out.println("当前余额：" + balance);
    }

    // 存款功能
    public void deposit(double amount) {

        balance += amount;

        System.out.println("存款成功");
        System.out.println("当前余额：" + balance);
    }

    // 查询余额
    public void checkBalance() {
        System.out.println("当前余额：" + balance);
    }
}
```
调用：
```Java
        ATM atm1 = new ATM("中国银行", 1000);//创建一个 ATM 类型的对象 为atm1

        // atm1 这个名字引用对象，new是Java中创建对象的关键字

        // 调用方法
        atm1.deposit(500);
        System.out.println(atm1.bank);
```

### 2. 封装

封装表示：写类的人，把这个类的属性和方法隐藏起来，只留一些可以访问的接口，让使用者可以访问，但是不能随意修改。
所以我们只知道 ATM 类有存款、取款、查询余额功能，但是不知道这些功能是怎么实现的，这就是封装。
本质上就是不让别人乱改对象内部的数据。

#### 为什么需要封装？

我们先看不封装的情况。

比如创建一个
```Java
public class ATM {

    String bank;
    double balance;
}
```
然后创建对象
```Java
ATM atm1 = new ATM();

atm1.balance = 1000;// 给 atm1 中的 balance 初始化1000，相当于这个ATM机中有1000块钱。
```
但是问题出在这里：别人可以随意修改这个 balance，比如：`atm1.balance = 99999`
这样是不合理的，因为ATM机中的钱，应该是ATM机自己来管理，不应该让用户随意修改。

所以，我们希望，ATM机中的钱，只能通过取款和存款来修改，不能随意修改。这就需要封装。

#### 如何封装？

```Java
private double balance;
```
private 表示私有，只有 ATM 自己能操作这个数据，外部代码不能直接改。

封装例子：
```Java
public class ATM {

    // 私有属性
    private double balance;

    // 构造方法,初始化 balance,意思是：创建 ATM 这个对象时，初始余额为多少。
    // 如果没有这个1000，那么 balance 默认会被初始化为0。
    // 因为 private 这个私有属性在，我们不能直接通过 ATM atm1 = new ATM(1000); 来初始化 balance为1000.
    // 而是需要写一个构造方法，通过构造方法在类的内部初始化 balance。
    public ATM(double balance) { 
        this.balance = balance;
    }
    // 存款
    public void deposit(double amount) {

        if (amount <= 0) {
            System.out.println("存款金额非法");
            return;
        }

        balance += amount;
        System.out.println("存款成功");
    }
    // 取款
    public void withdraw(double amount) {

        if (amount > balance) {
            System.out.println("余额不足");
            return;
        }

        balance -= amount;
        System.out.println("取款成功");
    }
    // 查询余额
    public void checkBalance() {
        System.out.println(balance);
    }
}
```
然后外部
```Java 
atm1.ATM(1000);//创建 ATM 对象，并初始化 balance 为1000
atm1.deposit(1000);//我们把1000作为变量传进类中的方法来实现修改.
```

### 3.继承

继承允许我们创建一个类（子类）继承另一个类（父类）的属性和方法。
子类可以继承父类的所有非私有属性和方法，也可以添加自己的属性和方法。

#### 例子

比如所有动物都有名字/年龄（属性），并且会吃东西（方法）
所以我们可以创建一个 Animal 类，然后让所有动物都继承这个类.

```Java
class Animal {
    String name;
    int age;

    public void eat() {
        System.out.println("动物在吃东西");
    }
    
    //构造函数
    public Animal （String name）{
        this.name = name;
    }
}
```
但是：
- 狗除了这些，还会 `bark()`
- 猫会`meow()`
于是
```
Animal
├── Dog
└── Cat
```
这就是继承，Dog 和 Cat 都继承了 Animal 的属性和方法，并且可以添加自己的属性和方法。
 
#### 继承的语法

然后具体怎么继承呢？
继承的语法：
```Java
class 子类 extends 父类 {
    // 子类的属性和方法
}
```
所以：
```Java
// 子类 Dog
public class Dog extends Animal {

    public Dog(String name) {

        // 调用父类构造函数
        super(name);
    }

    public void bark() {
        System.out.println(name + "：汪汪！");
    }
}

//子类 Cat
public class Cat extends Animal {

    public Cat(String name) {
        // 调用父类构造函数
        super(name);
    }

    public void meow() {
        System.out.println(name + "：喵喵！");
    }
}
```
于是 Dog 和 Cat 都有了 name 属性和 eat() 方法。
所以 dog.eat() 可以直接用。


##### 构造函数是什么？

构造函数是类的一种特殊方法，用于**创建对象时初始化对象的属性**。
构造函数的**名称**与**类名**相同，没有返回类型，并且可以接受参数。**不能写返回值**

普通方法是对象创建以后，给对象执行功能的。
构造函数是对象创建的时候，给对象初始化的。

相当于给 ATM机 的出厂初始化：设置编号，银行，余额等。

```Java
public class Animal {
    String name;
    int age;

    public Animal(String name, int age) {
        this.name = name;
    }
}
```
构造函数也可以对变量做运算等，也可以调用方法,创建对象。

##### super 是什么？

super 关键字用于调用父类的**构造函数**、方法和属性。
本质是父类的那一部分。

比如 `class Dog extends Animal`,说明Dog里面包含了一份Animal的内容。

- super()：调用父类的构造函数。
- super.属性名：调用父类的属性。
- super.方法名()：调用父类的方法。

```Java
    public Cat(String name) {
        // 调用父类构造函数
        super(name);// 从Animal类中调用name属性
    }
```

### 4.多态

多态本质上是同一个方法调用，但不同对象有不同表现。

#### 例子：
比如：父类
```Java
class Animal {

    public void sound() {
        System.out.println("动物发出声音");
    }
}
```
子类Dog
```Java
class Dog extends Animal {

    @Override
    public void sound() {
        System.out.println("汪汪！");
    }
}
```
子类Cat
```Java
class Cat extends Animal {

    @Override
    public void sound() {
        System.out.println("喵喵！");
    }
}
```

使用：
```Java
public class Main {

    public static void main(String[] args) { //主函数入口，代码从这里执行。
        Animal a1 = new Dog(); // a1是Animal类型，但实际指向的是Dog对象，因为创建的是Dog对象。
        Animal a2 = new Cat();
        a1.sound();
        a2.sound();
    }
}
```
`Animal a1 = new Dog();`这段代码，a1是Animal类型，但实际指向的是Dog对象，所以调用sound()方法时，实际调用的是Dog的sound()方法。
所以，实际上执行的是：Dog的sound(),不是Animal的sound()。
不是Animal来分配，是Java运行时会看对象的真实类型。

这就是多态。同一个方法，不同的对象，有不同的表现。
```
同样是 sound()

Dog 调用 → 汪汪
Cat 调用 → 喵喵
```

##### 什么是 @Override ?     

`@Override` 是一个提示，没有在代码逻辑上的功能，只是用来告诉编译器，这个方法是重写父类的方法。如果父类没有这个方法，编译器会报错。
不是必须的，但建议加上，可以避免一些错误。

比如
```Java
@Override
public void sound()
```
是在告诉Java：我这里的Dog的sound()方法，是重写Animal的sound()方法。
重写就是:子类把父类的方法，改成自己的实现。
但是方法名/参数一样，返回值兼容。

### 5. 抽象

抽象，就是抽象出共有的部分，把共有的部分，提取出来，形成一个抽象的类。
本质上是一个半成品父类。

比如：动物都会叫，但是：

- 狗怎么叫？
- 猫怎么叫？

我们不知道，所以，我们抽象出一个Animal类，然后让子类去实现。
父类只能规定：所有动物都必须有sound()方法，但是具体怎么叫，父类不知道，只能让子类去实现。

```Java
public abstract class Animal {

    public abstract void sound(); //没有{},因为Animal不知道具体怎么叫。只是规定：子类必须有sound()方法。
}
```
`abstract` 意思是：这不是一个完整的类。

**抽象类，不能被实例化，不能直接创建对象。**

因为抽象类不完整，就相当于：你不能创建一个不知道怎么叫的动物。

### 6. 接口

接口更**抽象**，只定义规则，不实现规则。

```Java
interface Animal {

    void sound();
}
```
这里甚至没有属性与实现，只有规则。
意思是：所有实现这个Animal接口的类，都必须实现sound()方法。

#### 实现接口：
```Java
class Dog implements Animal {

    @Override
    public void sound() {

        System.out.println("汪汪");
    }
}
```



##### implements 和 extends 的区别

- `implements` **遵守某种规则**。实现接口，必须实现接口中定义的所有方法。
- `extends` **是一个** 。继承类，可以不实现父类的方法，但是必须实现接口中定义的所有方法。


#### 接口的多继承

一个类可以实现多个接口，但是只能继承一个类。Java类不能多继承。

比如：Dog 可以同时存在：会游泳，会跑。
但是 Dog 不能同时属于Animal和Machine。会出现冲突问题。

比如A,B两个类，都有sound()方法，那么Dog类，不知道该继承哪个sound()方法。

接口自身也能多继承，比如：
```Java
interface Animal {

    void eat();
}
interface Flyable {

    void fly();
}
interface Bird extends Animal, Flyable {

}
```

##### 多继承示例
```Java

interface Animal {

    void sound();//会叫
}

interface Runnable {

    void run();//会跑
}
class Dog implements Animal, Runnable {

    @Override
    public void sound() {

        System.out.println("汪汪");
    }

    @Override
    public void run() {

    } //同时存在会叫和会跑两个方法
}
```
