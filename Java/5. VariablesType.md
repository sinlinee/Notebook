# Java变量类型

声明变量时，需要遵循以下语法：

type indetifier [= value][, identifier [= value] ...] ;

其中，type表示变量的类型，identifier表示变量的名称，value表示变量的初始值。

## 变量类型

### 变量的生命周期

变量生命周期指的是变量在程序运行期间存在的时间段。

### 局部变量

定义在方法内部：

```Java
public class Test {

    public void hello() {

        int age = 18;
        System.out.println(age);
    }
}
```
局部变量只在方法内部有效，方法结束后，局部变量就会被销毁。

局部变量必须初始化，因为不会自动赋值。

### 参数变量

特殊的局部变量

```Java

public void hello(String name int age) {
    

}
```
这里的name和age就是参数变量。
是方法被调用时传入的值。

比如我们调用`hello(Miyo, 18)`，那么name就是Miyo，age就是18。

生命周期和局部变量一样，方法结束后就会被销毁。

### 实例变量/成员变量

定义在类内部，方法外部：

```Java
public class Test {

    int age;
    String name;
}
```

实例变量在对象创建时被初始化，生命周期和对象一样，对象被销毁时，实例变量也会被销毁。
实例变量可以被所有方法访问，包括静态方法。
实例变量存在堆里。
实例变量有默认值，即使没赋值，也会被初始化为0。

| 类型      | 默认值   |
| ------- | ----- |
| int     | 0     |
| long    | 0L    |
| double  | 0.0   |
| boolean | false |
| 引用类型    | null  |


### 静态变量

定义在类内部，方法外部，使用static修饰：

```Java
public class Dog {
    static int count = 0;

}
```
静态变量属于类本身，不属于某个对象，使用Dog.count就能直接访问。

所有对象共享一个静态变量，修改后所有对象都能看到修改后的值。

---

图解：

```Java
class Dog {

    static int count; // 静态变量

    String name;      // 实例变量

    void hello(int age) { // age 参数变量

        int x = 10;       // 局部变量

    }
}
```

## 访问修饰符

| 修饰符   | 当前类 | 同一包内 | 子类  | 所有类 |
| ------ | ---- | ---- | ---- | ---- |
| public | Y    | Y    | Y    | Y    |
| protected | Y    | Y    | Y    | N    |
| default | Y    | Y    | N    | N    |
| private | Y    | N    | N    | N    |、

访问修饰符本质就是在控制：谁能访问这个东西。

### 包

package = 文件夹+命名空间

#### 包的作用是什么?

解决重名冲突
方便代码管理

#### 如何使用？

1. 声明包：`package com.moe.project.model;`

声明这个类在哪个包里，必须放在文件开头，不能和类名放一起。

2. 使用包：`import com.moe.project.model.Dog`

把其他包的类导入进来，就可以直接使用。

#### Tips

1. 如果一个类没有声明包，那么它属于默认包，不建议使用。
2. 如果一个类没有导入包，那么它只能使用默认包和本包的类。
3. 同一个包不需要导入
4. java.lang包下的类不需要导入，因为java.lang包是默认导入的。

### private

private修饰的变量只能在本类中访问，其他类都访问不了。

### default

default修饰的变量可以在本类和同一包内访问，其他类都访问不了。

### protected

protected修饰的变量可以在本类、同一包内、子类中访问，其他类都访问不了。

### public

public修饰的变量可以在本类、同一包内、子类、其他类中访问。
