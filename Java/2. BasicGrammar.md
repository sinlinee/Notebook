# Java基础语法

```Java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World"); 
    }
}
```
Java是一种面向对象的强类型语言，所以基本上所有的代码都由类组成，每个Java程序都至少有一个类，类是Java程序的基本组成单位。

## 第一行 public class HelloWorld

这是在定义一个类：
- 类名是HelloWorld
- public表示这个类是公共的，可以被其他类访问。

Java要求：类名必须和文件名相同，所以这个文件必须命名为HelloWorld.java。类名通常要首字母大写。

一个文件中**只能有一个**public类，可以有多个非public类。

## 第二行 public static void main(String[] args)

这是Java程序的入口，程序从这里开始执行。

- public 表示JVM能够访问它，如果不是public，JVM将无法找到main方法。
- static 表示main方法是静态的，不需要创建对象就可以调用。
  因为程序刚启动时，JVM还没有创建任何对象，所以只能调用static方法。
- void 表示main方法没有返回值。如果有数据类型，则用return返回。
- main表示方法名，是JVM识别的特殊方法名。JVM会专门寻找main作为主入口。

**JVM 规定：程序入口必须是public static void main(String[] args)**

### 参数 String[] args

- String[] 表示字符串数组，可以用来存储命令行参数。
- args 是参数名，可以任意命名，但一般使用args。
所以意思是：名字叫args的 字符串数组。

#### 为什么main方法要接收一个String数组参数？

因为Java程序启动时，可以从命令行接收参数，这些参数被存储在args数组中，通过main方法的参数传递给程序。

比如我们运行
```bash
java HelloWorld aaa bbb ccc
```

这里的aaa、bbb、ccc就是命令行参数，会被传递给main方法的args数组。
所以 args 就变成了：
```Java
args[0] = "aaa"
args[1] = "bbb"
args[2] = "ccc"
```

我们可以在程序中通过args数组来访问这些参数。

```Java
public class HelloWorld {

    public static void main(String[] args) {

        System.out.print(args[0]);
        System.out.print(args[1]);

    }

}
```
这时如果运行`java HelloWorld Alice 18` ，输出结果就是：Alice 18。

其实args可以改名，但习惯为args。



## 第三行 System.out.println("Hello World");

这是在调用System类的静态方法out的println方法，输出字符串"Hello World"。

- System 是一个系统类，提供了系统相关的功能。
- out 是System类的一个静态成员变量，表示标准输出流，通常用来向控制台输出信息。
