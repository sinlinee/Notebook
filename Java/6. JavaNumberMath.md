# Java Number类

## 1. Number类

Number类是Java的数值类型的父类，它是一个抽象类，不能被实例化。Number类提供了将数值类型转换为字符串的方法，以及将字符串转换为数值类型的方法。

Number类有四个子类：Byte、Short、Integer、Long，它们分别对应Java中的四种基本数据类型：byte、short、int、long。

Number类还提供了将数值类型转换为其他数值类型的方法，例如将int类型转换为float类型的方法。

## 2. 为什么需要Number类？

因为Java的基本类型不是对象。

可以 int a = 10；但是Java的泛型不能放基本类型，所以需要Number类：List<Integer>

## Number的作用：

1. 将基本数据类型封装成对象；
2. 提供了更丰富的方法操作这些数据；

比如：Number n = 10; 实际上是：Number n = new Integer(10);
