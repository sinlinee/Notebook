# Java 基本数据类型

变量通过申请内存在存储值，而内存空间的大小取决于变量的数据类型。
内存管理系统根据变量类型来为变量分配存储空间，分配的空间大小会因数据类型的不同而不同。

Java 的基本数据类型有 8 种，分别是：byte、short、int、long、float、double、boolean、char。

## byte

- byte 数据类型是8位、有符号的，以二进制补码表示的整数；
- 最小值是 -128（-2^7）；最大值是 127（2^7-1）；
- 默认值是 0；
- byte 类型用在大型数组中节约空间，主要代替整数，因为 byte 变量占用的空间只有 int 类型的四分之一；
- 例子：byte a = 100，byte b = -50。

## short

- short 数据类型是 16 位、有符号的以二进制补码表示的整数；
- 最小值是 -32,768（-2^15）；最大值是 32,767（2^15 - 1）；
- Short 数据类型也可以像 byte 那样节省空间。一个 short 变量是 int 变量的二分之一；
- 默认值是 0；
- 例子：short s = 1000，short r = -20000。

## int

- int 数据类型是 32 位、有符号的以二进制补码表示的整数；
- 最小值是 -2,147,483,648（-2^31）；最大值是 2,147,483,647（2^31 - 1），大概21亿。
- 一般地整型变量默认为 int 类，；即使数值超过int类型的范围，也会被默认为int，只是精度会丢失；
- 默认值是 0；

## long

- long 数据类型是 64 位、有符号的以二进制补码表示的整数；
- 最小值是 -9,223,372,036,854,775,808（-2^63）；最大值是 9,223,372,036,854,775,807（2^63 -1），大概9万万亿。
- 这种类型主要使用在需要比较大整数的系统上；
- 默认值是 0L,这个**L**是告诉Java这是一个long类型，而不是int类型；比如我们赋一个值：9999999999 (100亿)，int是装不下的，但是long可以装下，所以赋值的时候要加L，否则会报错。

## float

- float 数据类型是单精度、32位、符合IEEE 754标准的浮点数；
- float 在储存大型浮点数组的时候可节省内存空间；
- 默认值是 0.0f，和long一样，这个**f**是告诉Java这是一个float类型，而不是double类型，Java会把小数默认为double类型，所以赋值的时候要加f；
- 浮点数不能用来表示精确的值，如货币；
- 例子：float f1 = 234.5f。

## double

- double 数据类型是双精度、64位、符合IEEE 754标准的浮点数；
- 浮点数的默认类型为double类型；
- double类型同样不能表示精确的值，如货币；
- 默认值是 0.0d，和long一样，这个**d**是告诉Java这是一个double类型，而不是float类型，但是Java会把小数默认为double类型，所以赋值的时候可以不加d，但为了可读性，建议加上；
- 例子：double d1 = 123.4d。

## boolean

- boolean数据类型表示一位的信息；
- 只有两个取值：true 和 false；
- 这种类型只作为一种标志来记录 true/false 情况；
- 默认值是 false；
- 例子：boolean one = true。

## char

- char类型是一个单一的 16 位 Unicode 字符；
- 最小值是 '\u0000'（即为0）；
- 最大值是 '\uffff'（即为65,535）；
- char 数据类型可以储存任何字符；
- 例子：char letter = 'A';

## 说明：

Java会先判断右边是什么类型，再看能不能赋值给左边。
所以不是左边决定右边，而是右边先有自己的合法类型。

## 引用类型 (安全版的指针)

变量里存的不是数据本身，而是数据的所在的位置。

```java
String s = "hello";
```
这里的s是一个引用，它指向"hello"这个字符串对象地址，而不是"hello"这个字符串本身。

实际上 s -> hello的地址，而hello的地址指向字符串对象。

所有class都是引用类型。包括用户自己写的类。

### 所以new到底做了什么？

比如`Dog d = new Dog();`实际上:JVM在堆内存中开辟了一块空间，存放Dog对象，然后d指向这块空间。

#### 堆/栈以及区别

堆是JVM中用于存放对象实例的区域，每个对象实例都会在堆内存中分配一块内存空间。
栈是JVM中用于存放局部变量、方法调用、方法返回值等的区域。

一个对象本身在堆里是连续存放的，比如创建``Dog d = new Dog();``,JVM会在堆里分配一整块内存给这个对象。
```ascii
Heap:

┌──────────────────┐
│ Object Header    │
├──────────────────┤
│ age (4字节)      │
├──────────────────┤
│ gender (1字节)   │
├──────────────────┤
│ padding(补齐)    │
└──────────────────┘
```
padding是为了对齐，因为CPU读取数据是按块读取的，比如4字节一块，所以需要补齐。通常填充一些随机数。

而栈里存放的是引用，比如``Dog d = new Dog();``，d在栈里，它指向堆里的对象。

其实就是C的指针：栈里存放对象的内存地址，然后堆实际上存放的是整个对象。

##### 区别

- 栈是线程私有的，每个线程都有自己的栈空间；
- 堆是线程共享的，所有线程共享同一个堆空间；
- 栈的空间较小，堆的空间较大；
- 栈的分配和回收速度较快，堆的分配和回收速度较慢；


- 引用类型包括：类、接口、数组；
- 默认值为 null；


## 常量

常量是程序中固定不变的值，一旦定义就不能改变。

```java
final int MAX_VALUE = 100;
```

常量名通常全部大写，以区别于变量。

常量在定义时必须初始化，否则编译器会报错。

常量可以被声明为 public static final，这样就可以在类的任何地方访问它，并且它不会被修改。

```java
public static final int MAX_VALUE = 100;
```

常量还可以被声明为 static final，这样就可以在类的任何地方访问它，但是它可以被修改。

```java
static final int MAX_VALUE = 100;
```

## 转义字符
转义字符是一种特殊的字符，它以反斜杠（\）开头，后面跟着一个或多个字符，表示一个特殊的含义。

常见的转义字符包括：

- \n：换行符
- \t：制表符
- \r：回车符
- \b：退格符
- \f：换页符
- \': 单引号
- \": 双引号
- \\：反斜杠

例如，以下代码将输出一个包含换行符和制表符的字符串：

```java
System.out.println("Hello\nWorld\t!");
```

输出结果为：

```
Hello
World	!
```

## 类型转换

类型转换有两种：隐式转换和显式转换。

隐式转换是指将一种数据类型自动转换为另一种数据类型，例如将整数转换为浮点数。

显式转换是指将一种数据类型强制转换为另一种数据类型，例如将浮点数转换为整数。

```java
int a = 10;
double b = a; // 隐式转换，将整数a转换为浮点数b
int c = (int) b; // 显式转换，将浮点数b转换为整数c
```
注意:
- 在显式转换中，如果转换不成功，可能会导致数据丢失或溢出。
- 不能对Boolean类型进行类型转换。
- 不能将一个对象类型转换为另一个不相关的对象类型。
- 大的转小的，需要强制转换，小的转大的，自动转换。
- 转换过程中，可能会丢失精度。
- 浮点数转换不会四舍五入，而是直接截断小数部分。
- 转换过程中，可能会出现溢出。
